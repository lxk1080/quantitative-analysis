# 量化分析工具需求文档

## 1. 目标与范围

本项目是面向个人研究的本地 A 股条件筛选工具。系统维护本地日线与指标数据，允许用户选择内置策略或构建自定义条件，并在盘中运行筛选、查看命中原因和个股日线。

范围不包括自动下单、券商交易连接、收益预测、投资建议、多用户协作或云端同步。

## 2. 用户流程

1. 初始化数据库并同步数据。
2. 在“筛选条件”中选择预设条件或新建自定义条件。
3. 运行筛选，等待后台任务完成。
4. 查看命中股票、当前价和条件说明，必要时导出 EBK。
5. 点击股票名称查看本地日线，或勾选“使用同花顺 K 线”后直接打开同花顺个股页。

## 3. 数据要求

### 3.1 股票范围

- 筛选与股票浏览以活跃、非 ST 的普通 A 股为默认范围。
- 自定义条件可分别排除 ST、科创板和北交所；三项默认勾选。
- 数据异常、指标不足或实时价格不可用的股票应标记为不可用，而不是静默当作不符合。

“不可用”是本次筛选的数据状态：直接原因是缺少完成条件判断所需的有效数据，例如盘中快照没有该股票报价、无法得到前复权价格，或历史日线与指标不足。停牌、行情源漏报/异常、个股数据缺失等可能造成这些情况；“不可用”不视为“不符合”。

### 3.2 日线与指标

- 本地每只股票保留最近 90 个交易日的有效日线。
- 日线 OHLC 使用前复权价格；成交量保持原始成交统计。
- 指标包括 MA5、MA10、MA60、DKX 和 MADKX10。
- 实时筛选使用盘中快照与历史日线组合；未收盘数据不得写入正式日线。

### 3.3 涨停显示

- 本地 K 线的涨停判断使用原始昨收与原始收盘价，不使用前复权价格。
- 主板按 10%、创业板/科创板按 20%、北交所按 30% 计算。
- 限制价格按 0.01 元最小变动单位四舍五入后比较，因此真实涨停的展示涨幅可略低于整数比例。

## 4. 筛选功能

### 4.1 预设与收藏

- 支持内置预设策略和自定义收藏策略。
- 自定义收藏保存为 `quant_worker/strategy_rules/collections/` 下的独立 JSON 文件，并包含名称、创建/更新时间与完整配置。
- 编辑收藏时，不应自动应用该条件；保存后返回筛选条件列表。
- 用户点击选择某项条件时，才将该项作为当前应用条件。

### 4.2 自定义条件

已启用条件以 AND 组合。支持以下条件：

| 条件              | 参数               | 规则                                |
| ----------------- | ------------------ | ----------------------------------- |
| 排除范围          | ST、科创板、北交所 | 分别控制是否排除                    |
| 涨停              | N                  | N 个交易日前涨停                    |
| K 线未破均线      | N、均线周期        | 最近 N 日最低价不低于均线           |
| 收盘价在 DKX 上方 | N                  | 最近 N 日收盘价高于 DKX             |
| 两月涨幅排名      | Top N              | 名次不大于 N                        |
| 连续涨幅区间      | N、下限、上限      | 连续 N 日涨幅均落在区间内           |
| 区间涨幅          | N、上限            | 最近 N 日区间涨幅小于上限           |
| 量比              | N、下限            | N 个交易日前的量比大于下限          |
| DKX 偏离          | 下限、N、上限      | 指定日收盘价相对 DKX 的偏离在区间内 |

量比规则：盘中使用“累计成交量 ÷ 已过交易分钟数”与此前 5 个交易日平均每分钟成交量比较；盘后或历史日使用目标日成交量与此前 5 日平均成交量比较。

### 4.3 筛选结果

- 展示代码、名称、状态、当前价（前复权）和命中说明。
- 说明列最多显示 18 个字符，完整内容通过悬停标题查看。
- 只显示命中结果；任务摘要仍显示命中数与不可用数。
- “不可用”计入摘要，不进入命中列表或 EBK 导出。
- 支持 EBK 导出。

## 5. 个股日线体验

- 默认打开本地可拖动日线窗口，标题格式为“名称 · 代码 · 日线”。
- 展示 K 线、成交量、MA5、MA10、MA60 和 DKX；图例显示最新可见值及对应颜色。
- 鼠标滚轮缩放横向可见 K 线，缩放锚定最新 K 线；按住左键可左右拖动查看历史。
- 图表文字不可被拖动操作选中。
- 普通上涨为红色空心，涨停为紫色空心，下跌为绿色实心；成交量柱采用同一涨跌颜色。
- 窗口提供“在同花顺打开”，在新标签页访问 `https://stockpage.10jqka.com.cn/{code}/`。

## 6. 运行要求

- 浏览器服务由 Next.js 提供。
- 筛选和同步均通过任务表异步执行，由 Python Worker 处理。
- 任务创建接口会按需启动一次 Worker；也支持单独启动常驻 Worker。
- SQLite migration 必须在首次使用前执行。

## 7. 验收标准

1. 新环境可完成依赖安装、migration、同步、筛选和结果查看。
2. 自定义条件可新建、收藏、编辑、删除；编辑不会意外改变当前应用条件。
3. 结果说明、导出、同花顺跳转和本地 K 线窗口可用。
4. 图表缩放、拖动和 K 线/成交量配色符合上述规则。
5. `npm run build` 和 Python 测试可通过。
